CS 330 Portfolio Reflection

1. How do I approach designing software?

I approach software design by starting with an idea and figuring out how to make it work. For my 3D scene, I learned how important it is to plan object placement, textures, lighting, and camera movement. I worked through the scene step by step and made changes when things did not look right. I can use this same approach in future projects by planning ahead, breaking problems into smaller parts, and testing my ideas as I go.

2. How do I approach developing programs?

While working on my 3D scene, I learned more about using C++ and OpenGL to create objects, apply textures, and control the camera. I had to test different settings and fix problems throughout the milestones. Sometimes I had to go back and change code to get the results I wanted. This taught me that programming takes patience and that making small changes and testing them can help solve problems. By the end of the project, I was more comfortable working with the code and understanding how the different parts of the scene fit together.

3. How can computer science help me reach my goals?

Learning computational graphics has helped me understand how 3D environments are created and how code can bring objects to life. These skills can help me in future computer science courses and give me a better understanding of how graphics work in video games. My goal is to become a video game programmer, so learning how to build a 3D scene has been useful experience. I still have more to learn, but this project helped me improve my programming skills and gave me more confidence in working toward my career goal.
